README Aggregated Benthic Cover data files

The following files were generated by running the raw ReefCloud data through a series of aggregation and cleaning scripts in python to aggregate raw data relevant to EcoRRAP's specific analyses requirements. 

NOTE: This document is a continuation of the README associated with the raw data 'raw_data_surveys_12.csv', therefore users should refer to that document and dataset for full details on how this dataset was generated.
Users are also encouraged to wrangle and sort the data according to their specific needs.

In the following files, each row represents the averaged values of cover across 12 images in each year for a given plot.

 - cover_estimate_DESCRIPTION: This is the mean cover per survey for all of the classes used in the EcoRRAP ReefCloud label set (e.g. highest taxonomic resolution). 
 - cover_estimate_GROUP: mean cover per survey for broad taxonomic groups as determined for EcoRRAP purposes (e.g. hard coral, soft coral, etc.) and individual users should group as they see fit for their purposes.


Fields included in above files:
 - survey_title: Name of the plot as it appears in the ReefCloud Project
 - Various ReefCloud classes as defined by the EcoRRAP Labelset
 - year: Year that the plot was imaged
 - site: abbreviation for EcoRRAP reef, including cluster and reef name. See bottom of this document for full 	 list of abbreviations
 - site_latitude: rough GPS coordinates of the reef location -  these are not plot level coordinates
 - site_longitude: rough GPS coordinates of the reef location 
 - depth_m: 5m average depth for shallow sites, 12m average depth for deep sites
 - site_reef_name: Full name of the reef (e.g. 'Heron Reef')
 - transect: EcoRRAP plot number (1-4)
 - project: ReefCloud project name (EcoRRAP-photoquadrat)
 - total: number of points annotated per image
 - survey_ID: ReefCloud specific ID
 - site_ID: ReefCloud specific ID
 

Important notes on the data:
- The deep and shallow flank sites at Moore Reef (ONMO_FL1D & ONMO_FL1S) were not imaged on the 2022 field trip due to logistical problems. 
	- Therefore they were imaged on a fieldtrip in February 2023 as well as the planned 2023 time point in October 2023. 
	- In this dataset, the 02/2023 imaging is considered as part of the 2022 dataset and both the survey title and year say 2022.

- The majority of images used were selected with a python script that maximised spatial coverage based on the plot's 3D model. 
	- Where less than 12 images were extracted, the remaining images were extracted manually (every 33rd photo). 
	- A record of plots and the number of images per plot that were manually extracted is available, contact Madison Becker (m.becker@aims.gov.au) for more information if required. 

--- EcoRRAP Abbreviations

Cluster Code:
 - OSHE: Offshore Southern, Heron Island Reef
 - OSLM: Offshore Southern, Lady Musgrave
 - ISKE: Inshore Southern, Keppel Islands (Great Keppel, Halfway, Middle, Miall, North Keppel)
 - OCCH: Offshore Central, Chicken Reef
 - OCDA: Offshore Central, Davies Reef
 - OCLB: Offshore Central, Little Broadhurst 
 - ICPA: Inshore Central, Palm Islands (Orpheus, Pelorus)
 - ONLI: Offshore Northern, Lizard Island
 - ONMO: Offshore Northern, Moore Reef
 - TSAU: Torres Strait, Aukane Reef
 - TSDU: Torres Strait, Dungeness Reef
 - TSMA: Torres Strait, Masig Island

Habitats (numbers associated with habitat abbreviation indicate multiple sites of a habitat type within a reef, e.g. BA1 is 'back 1' while BA2 is 'back 2'):
 - BA: back reef
 - FL: flank reef
 - FR: front reef
 - LA: lagoon reef
